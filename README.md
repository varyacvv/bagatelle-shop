# 👜 BAGATELLE — Online Bag Store

## RU

### О проекте

**BAGATELLE** — концепт интернет-магазина стильных сумок ручной работы.

Проект выполнен с акцентом на минималистичный визуальный стиль, типографику и аккуратную структуру интерфейса. Страница содержит навигацию, каталог товаров с изображениями и ценами, информационный блок о бренде и footer.

Основная цель проекта — практика **семантической HTML-разметки, SCSS и организации frontend-проекта с использованием Gulp**.

### ✨ Возможности

* Каталог товаров
* Карточки товаров с изображением, названием и ценой
* Навигационное меню
* Информационный блок о магазине
* Адаптивная структура страницы
* Организованная SCSS-архитектура
* Компиляция SCSS в CSS с помощью Gulp
* Source maps для удобной разработки

### 🛠 Технологии

* HTML5
* SCSS / Sass
* Gulp
* JavaScript
* CSS
* Git / GitHub

### Сборка проекта

Для работы с проектом необходимо установить зависимости:

```bash
npm install
```

Компиляция SCSS выполняется с помощью Gulp:

```bash
npx gulp sass-compiler
```

Исходные SCSS-файлы находятся в `src/styles/`, а скомпилированные CSS-файлы — в `build/styles/`.

## ENG

### About the Project

**BAGATELLE** is a concept online store for elegant handmade bags.

The project focuses on a clean visual style, typography and structured interface. The page includes navigation, a product catalog with images and prices, an about section and a footer.

The main goal of the project was to practice **semantic HTML, SCSS and frontend project organization using Gulp**.

### ✨ Features

* Product catalog
* Product cards with images, names and prices
* Navigation menu
* About section
* Responsive page structure
* Organized SCSS styles
* SCSS compilation with Gulp
* Source maps for development

### 🛠 Tech Stack


Source SCSS files are located in `src/styles/`, while compiled CSS files are generated in `build/styles/`.
